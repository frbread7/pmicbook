## Evidence handling

- The chronology comparison uses full patent description text and exact paragraph/step/figure locators. No abstract-only source was used to infer process order.
- Patent implant energies, doses, and temperatures are not reproduced as recommended recipe values. Where the patents say “for example,” that language remains embodiment-specific.
- The Hower paper and MIT lecture are included only for narrow physics framing. Neither is used to infer a fabrication sequence.
- No source in this set establishes how frequently a given gate/P-body order is used in production. That remains unknown.
