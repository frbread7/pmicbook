# PMICBook vision and deferred ideas

PMICBook’s current product is the single-book v1 milestone described in [CURRENT_MILESTONE.md](CURRENT_MILESTONE.md). This file records possible later directions only. Listing an idea here does not authorize implementation or expand v1.

## Future directions

- Improve and extend PMIC/BCD lessons based on learner feedback, with source-backed examples and focused v1.x corrections.
- Consider further interactive device or system visualizations after the current educational models and their limitations are validated.
- Consider a broader semiconductor learning library only after PMICBook is complete and its architecture has been evaluated from delivery experience.
- Consider a generic case-first engineering structure as a separately scoped learning-design experiment; do not make it the current PMICBook milestone.

## Explicitly deferred systems

These are outside PMICBook v1 and must not be introduced as part of this milestone:

- Internal company knowledge, workplace document ingestion, private case/RCA repositories, and enterprise editing or authentication.
- An internal OpenCode overlay or other workplace-specific knowledge tooling.
- Retrieval-augmented generation (RAG), vector databases, graph databases, Zettelkasten infrastructure, and knowledge-graph interfaces.
- Yield-RCA integration, DevicePhysicsBook, MetrologyTestBook, YieldDefectBook, FailureAnalysisBook, or a generalized Semiconductor Engineering Library.
- A shared `semibook-core` repository or framework extraction.
- A MemoryBook fork or uncontrolled merger of a second codebase.

Reassess these directions only as a separately scoped future milestone. PMICBook v1 should first demonstrate a finished, maintained textbook using the ProcessBook base.
