Cite a source next to the technical claim or simulator assumption it supports, and distinguish source statements from PMICBook’s explanatory interpretation. Check publication details and access before relying on a source in final lesson text.

## Citation and simulator rules

- Link the cited public source from the chapter where a claim appears; add author/date or document identifier when established from the source itself.
- Use representative numerical values only when a public source supports them and the stated conditions are comparable. Otherwise label the value an illustrative assumption and show the equation, units, and valid range.
- Do not represent vendor examples, standards listings, or one published structure as foundry-neutral specifications. Do not use confidential or workplace material.
- Add references as the lessons are authored. Remove or revise unsupported claims rather than treating this index as blanket support.
